# Un recuerdo para Amy

Experiencia web cinematográfica y mobile-first construida con Vite, JavaScript, CSS y Canvas.

## Probar

```powershell
pnpm install
pnpm dev
```

## Producción

```powershell
pnpm build
pnpm preview
```

## Audio de la introducción

El cántico `Somos un equipo valiente y luchador Osasuna.mp4` se reproduce únicamente durante la introducción y se detiene mediante un fundido al entrar en el contenido. Los originales JPEG permanecen intactos; la web consume versiones WebP optimizadas.
